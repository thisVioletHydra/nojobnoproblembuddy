# Политика конфиденциальности Chrome-расширения NoJobNoProblemBuddy

Редакция от 20 октября 2026 г. Вступает в силу 20 октября 2026 г. Разработчик: ЧЕРНОВИК (далее — Оператор), ЧЕРНОВИК.

## 1. Назначение
Расширение помогает пользователю заполнять и отправлять отклики на вакансии на сайте вакансий, открытом в его браузере, по шаблонам и настройкам, заданным в веб-панели NoJobNoProblemBuddy. Единственная цель расширения — эта функция.

## 2. Какие данные собирает расширение
- **Содержимое страниц сайта вакансий** (текст и параметры вакансий, ссылки, статус отклика) — только на сайтах, указанных в разрешениях расширения, только для подбора вакансий и формирования отклика.
- **Данные аутентификации** — токен сессии веб-панели, чтобы связать расширение с аккаунтом.
- **HTML страниц сайта вакансий и значения полей форм** (без паролей) — передаются на сервер для работы автопилота и обрабатываются в памяти без сохранения.
- **Личные данные, которые пользователь сам ввёл** — профиль (анкета), сопроводительное письмо, факты, «Память», «Правила»; передаются на сервер и обрабатываются в памяти на время работы.
- **История действий в рамках функции** — какие отклики отправлены и когда.
Расширение **не собирает** историю браузера вне сайтов вакансий, пароли, платёжные данные, данные о местоположении, нажатия клавиш, переписку.

## 3. Зачем и кому передаются данные
| Получатель | Что | Зачем |
|---|---|---|
| Сервер NoJobNoProblemBuddy (Railway, США) | история вакансий и откликов, токен сессии, HTML страниц и поля форм (без хранения) | работа автопилота, история и синхронизация с веб-панелью |
| ИИ-сервис, подключённый пользователем | текст вакансии, данные шаблона | генерация сопроводительного текста по команде пользователя с его ключом |
| Сайт вакансий | отклик | отправка отклика из учётной записи пользователя (через расширение или сервером через API с токеном пользователя) |
| Telegram | краткое уведомление | уведомления, если пользователь их включил |
Все передачи защищены HTTPS.

## 4. Заявление о соответствии политике Chrome Web Store
The use of information received from this extension adheres to the **Chrome Web Store User Data Policy, including the Limited Use requirements**.

Использование данных, получаемых расширением, соответствует Политике Chrome Web Store в отношении пользовательских данных, включая требования Limited Use. В частности, мы:
- используем данные только для предоставления и улучшения единственной функции расширения, описанной выше;
- **не продаём** данные пользователей;
- не передаём данные третьим лицам, кроме случаев, необходимых для функции, по команде пользователя, для обеспечения безопасности, выполнения требований закона или при реорганизации с уведомлением пользователя;
- не используем и не передаём данные для персонализированной рекламы, определения кредитоспособности или кредитования;
- не позволяем людям читать данные пользователей, кроме случаев явного согласия пользователя, необходимости для безопасности, требований закона или обезличенных агрегированных данных для внутренних операций.

## 5. Хранение и удаление
Локальные данные расширения удаляются при его удалении из браузера. Данные на сервере хранятся, пока действует аккаунт, и удаляются в течение 30 дней после запроса на удаление. Удаление аккаунта и данных — по запросу Оператору; отдельные подключения (Telegram, ИИ-сервис, сайт вакансий) можно отвязать в настройках. Токены и ключи хранятся в зашифрованном виде (AES-256-GCM); ключ шифрования хранится в переменной окружения, отдельно от данных.

## 6. Ответственность пользователя
Пользователь сам отвечает за соблюдение правил сайта вакансий, включая ограничения на автоматизацию и риск блокировки учётной записи, а также за условия подключённого им ИИ-сервиса.
